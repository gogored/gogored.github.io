プライバシーポリシー

最終更新日：2026年10月31日

「バケ男分析」（以下「本ツール」）は、YouTube チャンネル「単発バケ男」の運営者が、自分のチャンネルを分析するためだけに使う個人用ツールです。

1. 取得する情報

本ツールは、運営者本人が Google アカウントで許可した場合に限り、次の情報を YouTube API Services から読み取ります。

  • YouTube Analytics の数字（再生回数、視聴時間、平均視聴率、視聴維持率、流入元、機器、年齢層など）
  • 自分のチャンネルと動画の基本情報（チャンネル名、動画のタイトル、公開日、長さなど）

権限は読み取りのみ（yt-analytics.readonly / youtube.readonly）です。動画の投稿・編集・削除、コメントの書き込みなどは一切しません。

2. 使い方

読み取った情報は、運営者本人のパソコンの中で分析レポートを作るためだけに使います。広告・販売・第三者への提供には使いません。

3. 保存と共有

  • 情報と許可の鍵（トークン）は、運営者本人のパソコンの中だけに保存します。
  • 第三者に売ったり、渡したり、公開したりしません。

4. 許可の取り消し

許可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）から取り消せます。取り消すと、本ツールは情報を読み取れなくなります。保存済みの情報は、運営者本人のパソコンから削除できます。

5. YouTube API Services について

本ツールは YouTube API Services を使っています。YouTube の利用規約（https://www.youtube.com/t/terms）と Google のプライバシーポリシー（https://policies.google.com/privacy）もあわせてご確認ください。

6. お問い合わせ

Google の許可画面に表示されるサポート用メールアドレスまでご連絡ください。
